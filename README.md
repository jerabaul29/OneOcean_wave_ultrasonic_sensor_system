# OneOcean_wave_ultrasonic_sensor_system

The OneOcean circumnavigation wave sensor system: hardware and software design of the system, post processing tools, data analysis.

The preprint describing the work is available at: https://www.researchgate.net/publication/374440999_Wave_Measurements_using_Open_Source_Ship_Mounted_Ultrasonic_Altimeter_and_Motion_Correction_System_during_the_One_Ocean_Expedition .

It is also available as a published article at: https://www.sciencedirect.com/science/article/pii/S0029801823029700 .

If using the contents of this repository, please consider referring to our published work:

```
Ølberg, J. T., Bohlinger, P., Breivik, Ø., Christensen, K. H., Furevik, B. R., Hole, L. R., ... & Rabault, J. (2024).
Wave measurements using open source ship mounted ultrasonic altimeter and motion correction system during the one ocean circumnavigation.
Ocean Engineering, 292, 116586.
```
